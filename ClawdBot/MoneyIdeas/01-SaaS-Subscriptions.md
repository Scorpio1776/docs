# ClawdBot - SaaS Subscription Revenue Ideas

## Overview

Subscription models provide recurring revenue. ClawdBot can offer tiered plans
that scale with user needs. Since you're bootstrapping, start with a free tier
to build a user base, then convert users to paid plans.

---

## Tier Structure

### Free Tier (Lead Magnet)
- Limited messages per day (e.g., 20 queries/day)
- Basic chatbot functionality
- ClawdBot branding on all outputs
- Community support only
- **Purpose**: Get users in the door, build word-of-mouth

### Starter Plan - $9/month
- 500 messages/day
- Basic API access (rate-limited)
- Email support
- Remove ClawdBot branding
- 1 custom bot persona
- **Target**: Individual developers, freelancers

### Pro Plan - $29/month
- Unlimited messages
- Full API access
- Priority support
- 5 custom bot personas
- Conversation history and analytics
- Webhook integrations (Slack, Discord, Teams)
- **Target**: Small businesses, power users

### Business Plan - $99/month
- Everything in Pro
- White-label option (their branding, not yours)
- Team accounts (up to 10 seats)
- Dedicated onboarding
- Custom training data / fine-tuning
- SLA guarantees
- **Target**: Growing companies, agencies

## Bootstrapping SaaS Implementation

### Phase 1 - MVP ($0 cost)
- Use free-tier LLM APIs (OpenRouter free models, or Claude/OpenAI free credits)
- Host on Vercel/Railway free tier
- Stripe for payments (no upfront cost, 2.9% per transaction)
- Simple landing page with waitlist

### Phase 2 - First Paying Users
- Offer lifetime deals on AppSumo or Product Hunt
- Use early revenue to cover API costs
- Gather feedback to refine tiers

### Phase 3 - Scale
- Move to dedicated infrastructure
- Introduce annual plans (20% discount = better cash flow)
- Add team/enterprise features

---

## Key Metrics to Track
- Monthly Recurring Revenue (MRR)
- Churn rate (aim for < 5% monthly)
- Customer Acquisition Cost (CAC)
- Lifetime Value (LTV) - target LTV:CAC ratio of 3:1
- Free-to-paid conversion rate (aim for 2-5%)
